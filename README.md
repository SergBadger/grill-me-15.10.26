# grill-me — скилл для Claude Code

Скилл, который **неотступно интервьюирует тебя** о плане, идее, дизайне или любой теме и после каждого ответа сохраняет всё в структурированный Markdown-файл. Ничего не теряется, даже если контекст чата переполнится.

Подходит для стресс-теста плана, мозгового штурма, исследовательской сессии или когда нужно «вытащить из головы» всё в документ.

## Установка

1. Скачай файл `grill-me/SKILL.md` из этого репозитория (или склонируй репозиторий).
2. Создай папку `grill-me` в папке скиллов Claude Code и положи туда `SKILL.md`:
   - **Windows:** `C:\Users\<имя пользователя>\.claude\skills\grill-me\SKILL.md`
   - **Mac / Linux:** `~/.claude/skills/grill-me/SKILL.md`
3. Перезапусти Claude Code.

Быстрый вариант через терминал (Mac / Linux / Git Bash на Windows):

```bash
mkdir -p ~/.claude/skills/grill-me && curl -L https://raw.githubusercontent.com/andrianov28/grill-me/main/grill-me/SKILL.md -o ~/.claude/skills/grill-me/SKILL.md
```

## Как пользоваться

Напиши в Claude Code:

- `/grill-me <тема>` — например, `/grill-me запуск нового курса`
- или просто: «прожарь меня», «давай устроим прожарку», «grill me»

Claude создаст файл `brainstorms/{дата}-{тема}.md` в текущей рабочей папке, будет задавать по одному вопросу за раз и записывать каждый ответ в файл. В конце — итог: что выяснили, какие решения приняты, что осталось открытым.
